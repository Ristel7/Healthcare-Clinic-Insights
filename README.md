🏥 Clinic Healthcare Analytics Power BI Dashboard

Overview

This repository contains a comprehensive healthcare dataset and interactive Power BI dashboards designed to provide insights into clinic operations, patient demographics, financial metrics, diagnostic outcomes, and physician performance. The project demonstrates practical healthcare analytics using Power BI visualizations to drive data-driven decisions and optimize management.

Repository Contents
Dataset: Clinic patient records including details on demographics, medical history, tests, visit compliance, financials, and physician scheduling.

Power BI Dashboards: Multiple screenshot files showcasing:

Clinical Overview

Patient Overview

Treatment & Outcomes Overview

Clinic Operations

Physician Overview

Financial Overview

Screenshots: Example visual outputs from Power BI, attached as .jpg images.

Featured Dashboards
1. Clinical Overview
Total patients, split by gender.

Average rating, average waiting time, and no-show rates.

High-level financials: revenue, cost, net profit, room utilization.

2. Patient Overview
Patients by age group and by month.

Patient visit compliance statistics (shown, missed, no-show).

Individual patient details: diagnosis, tests, results.

3. Treatment & Outcomes Overview
Treatments provided per diagnosis.

Patient outcomes by result type.

Month-wise trend of result types (normal, abnormal, critical, positive, negative).

4. Clinic Operations
Document completeness.

Reasons for patient visits.

Patient shows and no-shows statistics.

Equipment status (available, maintenance, in use).

5. Physician Overview
Physician schedules and patient load by time of day.

Patient distribution by physician.

Average days between patient visits.

6. Financial Overview
Revenue and cost breakdowns by treatment, physician, and month.

Profit margin and per-patient financial metrics.

Revenue and cost trends, summary tables.

Dataset Description
Columns Include:

Patient_ID, Age, Gender, Location, Medical_History, Diagnosis

Test_Type, Test_Result, Date_of_Test, Follow_Up_Recommendation

Booking_Time, Cancellations, No_Shows, Wait_Time_Min

Feedback_Score, Doctor_Schedule, Nurse_Schedule, Patient_Load

Room_Usage, Equipment_Availability, Supply_Inventory

Services_Billed, Payment_Status, Insurance_Claims, Consultation_Fees, Process_Time

...and more.

Suitable for statistical analysis, predictive modelling, business intelligence, and showcasing dashboard skills.

How to Use
Dataset: Use for data analytics practice or as a foundation for other BI/reporting projects.

Power BI Dashboards: Open the screenshots for visual examples, or rebuild using the dataset for hands-on BI experience.

Customization: Add new datasets, enhance visuals, connect with live data sources for advanced scenarios.
